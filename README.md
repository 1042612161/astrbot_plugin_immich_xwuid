# Immich 鸣潮图库同步 AstrBot 插件

适配 AstrBot **4.29.4 及以上 4.x**，只支持 OneBot v11（aiocqhttp）。插件在 AstrBot 插件页提供映射管理，可将 Immich 角色相册对应到 XWUID 已有的面板图、背景图角色目录。

## 安装与配置

将整个 `astrbot_plugin_immich_xwuid` 目录放入 AstrBot 的 `data/plugins/`，重启或在插件管理页加载插件。安装 `requirements.txt` 中的依赖后，在插件配置中填写：

- Immich 站点根地址与 API Key。API Key 需要允许读取/上传资产、创建相册，并查看账号列表与共享相册。
- XWUID 编辑台站点根地址、用户名和密码。用户名目前必须为 `admin`；密码对应 GSUID 的 `WavesPanelEditPassword`。

在 AstrBot 管理面板的插件详情页打开“鸣潮图库映射”，刷新列表后编辑面板图、背景图的映射并保存。插件会将匹配到的 Immich 相册和 XWUID 角色作为下拉选项，不允许在插件中新增或删除 XWUID 角色。页面也支持多选角色并直接同步相应类型的图片，界面会显示进度和失败明细。

WebUI 可编辑面板图和背景图的规格名称，默认分别为“竖图”“横图”，自动匹配和创建相册采用“角色名-规格名称”。修改任一规格名称并点击“保存设置与映射”后，两张映射表都会清空，按新名称匹配已有相册；没有匹配到的角色保持未映射。此操作不重命名或创建 Immich 相册。规格名称未保存时，页面会阻止创建相册和启动同步，避免使用旧名称。

映射表每个角色只出现一次。将某行角色切换到另一行已有角色时，两行会交换角色分配，相册选择各自保留。修改后需保存才对同步生效。升级时会保留旧版手工映射，直到用户修改规格名称。

同步结果只在当前页面展示，不保存任务历史。服务端在任务运行期间暂存进度；最终结果被页面读取后立即释放。若页面关闭或断网，尚未读取的结果会在任务结束 30 秒后自动释放，运行中的同步继续执行。刷新或关闭页面后无法恢复结果。

## 指令

以下指令初始权限为 AstrBot 管理员，可在“管理行为”中调整：

| 指令 | 说明 |
|---|---|
| `上传相册 折枝` | 优先处理本条消息图片，无图时读取引用；按比例归入已配置的角色相册。方图归入面板图相册。 |
| `同步背景图相册 折枝，洛可可` | 同步配置映射的多个角色背景图相册。 |
| `同步面板图相册 折枝` | 同步配置映射的角色面板图相册。 |

“上传相册”优先使用已保存的角色相册映射；没有映射时使用“角色名-规格名称”。默认生成“折枝-竖图”和“折枝-横图”。本条消息和引用消息均有图片时，只处理本条图片；图片链接重复时只处理一次。引用内容缺失时会通过 OneBot 获取引用消息，失败会给出提示。

同步命令支持中文或英文逗号、逗号两侧空格，例如 `同步背景图相册 折枝， 洛可可`；空项会忽略，重复角色只同步一次。

创建相册按钮点击后直接执行，会按已保存的规格名称为 XWUID 每个角色补齐相册，并共享给当前所有 Immich 账号，权限为可编辑。逐图同步会检查横竖比例，调用 XWUID 自带的相似图片检查；被判为重复的图片会跳过并计入进度。失败明细会回复到指令会话。

## 安全与测试

插件不会自动向生产服务执行写入；首次同步、相册创建和图片上传均由管理员操作触发。请在使用前确认 API 地址、权限与映射。不要在仓库中提交 API Key 或密码。

在插件目录的上一级运行离线测试（需要已安装 AstrBot 和插件依赖）：

```sh
python -m unittest discover -s astrbot_plugin_immich_xwuid/tests -v
node astrbot_plugin_immich_xwuid/tests/test_webui.mjs
```

测试使用模拟 HTTP 响应和“折枝”示例，不连接 Immich 或 XWUID 服务。

v1.0.2 已使用 AstrBot 4.29.4 官方发布包在隔离目录验证，33 项 Python 测试、8 项前端交互测试通过；未执行生产写入或真实机器人联调。
