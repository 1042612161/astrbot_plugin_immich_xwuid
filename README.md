# Immich 鸣潮图库同步 AstrBot 插件

适配 AstrBot **4.29.4 及以上 4.x**，只支持 OneBot v11（aiocqhttp）。插件在 AstrBot 插件页提供映射管理，可将 Immich 角色相册对应到 XWUID 已有的面板图、背景图角色目录。

## 安装与配置

将整个 `astrbot_plugin_immich_xwuid` 目录放入 AstrBot 的 `data/plugins/`，重启或在插件管理页加载插件。安装 `requirements.txt` 中的依赖后，在插件配置中填写：

- Immich 站点根地址与 API Key。API Key 需要允许读取/上传资产、创建相册，并查看账号列表与共享相册。
- XWUID 编辑台站点根地址、用户名和密码。用户名目前必须为 `admin`；密码对应 GSUID 的 `WavesPanelEditPassword`。
- 嵌套转发最大深度（`forward_max_depth`）：默认 `1`，可设为 `0`。被引用的转发本体按第 0 层读取，默认允许再展开一层嵌套转发；超出深度的转发不再读取。
- 最多处理图片数（`forward_max_images`）：默认 `50`，最小为 `1`。对本条消息、引用及转发内图片统一生效，按读取顺序去重后保留前 N 张。超出数量或深度时，命令结果会说明已截断。配置保存后下次命令读取新值。

在 AstrBot 管理面板的插件详情页打开“鸣潮图库映射”，刷新列表后编辑面板图、背景图的映射并保存。暗色工作台提供两个映射页签、可搜索的下拉框及独立的同步类型页签。角色按中文名称升序排列，同名时按 ID 排序；角色搜索支持名称或 ID。相册下拉只显示名称以当前类型的「-规格名称」结尾的相册，不允许在插件中新增或删除 XWUID 角色。

WebUI 可编辑面板图和背景图的规格名称，默认分别为“竖图”“横图”，自动匹配和创建相册采用“角色名-规格名称”。修改任一规格名称并点击“保存设置与映射”后，两张映射表都会清空，按新名称匹配已有相册；没有匹配到的角色保持未映射。此操作不重命名或创建 Immich 相册。规格名称未保存时，页面会阻止创建相册和启动同步，避免使用旧名称。

映射、保存校验和同步目标统一以 XWUID 的 `char_id` 为唯一键。每个 ID 在同一张映射表只出现一次；同名不同 ID 独立配置，也允许多个角色使用同一相册。漂泊者直接显示接口返回的名称和 ID，不增加性别标记。切换到另一行已有角色时，两行交换角色分配，相册选择各自保留，并重新按名称排序。此版本用于全新配置，不迁移旧版按名称保存的映射。

同步选择项与已选标签均显示「角色名 · ID」。面板图和背景图分别保留选择；搜索和“全选当前结果”不会清空搜索范围外的选择。映射或规格改动尚未保存时，页面会阻止同步及创建相册。任务状态区位于配置区下方，随页面正常滚动；结果就地展开，失败明细可滚动查看。开始任务不会强制跳转滚动位置。

WebUI 和聊天同步共用同一个后台执行器，同一时间只运行一个同步任务。关闭页面、浏览器或聊天处理结束不会主动取消已启动的后台任务；重新打开 WebUI 会读取最近任务，运行中自动连接进度，完成后恢复结果。网络暂时断开只影响页面读取，页面会重试，不把连接故障误报为任务失败。

只通过 AstrBot 插件 KV 持久化一份 `latest_sync`，下次任务启动时覆盖，不建立历史任务字典。记录包含任务类型、角色 ID、时间、进度、成功/重复/失败总数和有限失败明细。每检查 5 张图片及角色开始、任务结束时更新快照；任务重启后显示的是最近成功保存的进度。失败明细最多 99 条，每条最多 2000 个字符，失败总数仍统计全部；超过明细上限时页面会说明。

内存中仅保留运行必需的任务对象、当前处理数据与并发锁，结束后释放后台任务引用。AstrBot 的 KV 层可能缓存最近快照，但同一键始终覆盖，不会随着任务次数增加而累积。进程重启或插件重载时，遗留的运行状态标记为“中断”，不自动重跑；完成结果保留至下次任务。单任务限制针对同一 AstrBot 插件实例，不作为多实例部署的分布式锁。

## 指令

以下指令初始权限为 AstrBot 管理员，可在“管理行为”中调整：

| 指令 | 说明 |
|---|---|
| `上传相册 折枝` | 优先处理本条消息图片，无图时读取引用；按比例归入已配置的角色相册。方图归入面板图相册。 |
| `同步背景图相册 折枝，洛可可` | 同步配置映射的多个角色背景图相册。 |
| `同步面板图相册 折枝` | 同步配置映射的角色面板图相册。 |
| `上传相册 1501` | 使用具体 XWUID 角色 ID 选择上传相册。 |
| `同步面板图相册 1501，1502` | 分别同步指定 ID 的角色相册。 |

“上传相册”优先使用已保存的角色相册映射；没有映射时使用“角色名-规格名称”。默认生成“折枝-竖图”和“折枝-横图”。本条消息和引用消息均有图片时，只处理本条图片；图片链接重复时只处理一次。引用内容缺失时会通过 OneBot 获取引用消息，失败会给出提示。引用合并转发时，会读取其中的图片组件并按配置展开嵌套转发；兼容 OneBot 节点列表、AstrBot Node/Nodes 组件，以及节点中 JSON/CQ 格式的图片段。仅有普通文本网址仍不当作图片。转发节点只有 OneBot 文件标识时，先调用 `get_image` 获取普通本地路径或 HTTP/HTTPS 地址，再按现有逻辑读取；不直接支持其他图片来源协议。

命令上传按文件原始字节的 SHA-1 精确查重。先读取目标共享相册中所有可见资产的校验和，已有同图则跳过；再调用 Immich `/api/assets/bulk-upload-check` 检查 API Key 所属账号的资产，命中则复用原资产、只加入目标相册。没有命中才上传，并携带 `x-immich-checksum` 请求头处理上传时的重复判断。图片已在目标相册中的返回按跳过处理，权限不足等其他错误仍计为失败。结果分别统计新上传、复用已有图片并加入相册、目标相册已存在跳过和失败。

回收站中有同图时提示先恢复，不自动恢复或删除；查重接口失败、返回异常或目标相册资产缺少有效校验和时，该张记为失败并继续处理其他图片。同一命令内仅在成功加入相册后记录校验和，失败图片不会被误认为已处理。校验和集合只在本次命令内暂存，不下载相册原图、不保存长期查重历史。此查重覆盖目标共享相册的可见图片及 API Key 所属账号资产，不扫描其他账号的私有图库，也不合并或清理已有重复资产。它不属于视觉相似判断，QQ 压缩、截图或重新编码后可能无法识别为同一张图；其他账号同时向共享相册上传同图时，也无法保证跨账号的原子去重。

同步命令支持中文或英文逗号、逗号两侧空格，例如 `同步背景图相册 折枝， 洛可可`；空项会忽略，重复角色只同步一次。

上传和同步均支持唯一角色名称或 ID。同名对应多个 ID 时会列出候选 ID 并要求明确选择，不会自动选中其中一个。不同名称解析到同一 ID 时只同步一次。

创建相册按钮点击后直接执行，会按已保存的规格名称为 XWUID 每个角色补齐相册，并共享给当前所有 Immich 账号，权限为可编辑。逐图同步会检查横竖比例，调用 XWUID 自带的相似图片检查；被判为重复的图片会跳过并计入进度。失败明细会回复到指令会话。聊天同步会发送启动提示及变化的进度，最终回复统计与最多 99 条失败明细；其最近状态也可在 WebUI 查看。

命令上传读取图片组件中的普通本地绝对路径或 HTTP/HTTPS 链接。AstrBot 已下载到本地的图片直接读取；同一组件同时包含本地路径和网络链接时，优先本地读取，失败后尝试网络链接。引用的纯文本图片网址不会被识别为图片，不支持 `file://`、Base64 或相对路径。XWUID 客户端自动携带编辑台要求的 `X-Waves-Panel-Edit: 1` 请求头。

## 安全与测试

插件不会自动向生产服务执行写入；首次同步、相册创建和图片上传均由管理员操作触发。请在使用前确认 API 地址、权限与映射。不要在仓库中提交 API Key 或密码。

在插件目录的上一级运行离线测试（需要已安装 AstrBot 和插件依赖）：

```sh
python -m unittest discover -s astrbot_plugin_immich_xwuid/tests -v
node --test astrbot_plugin_immich_xwuid/tests/test_webui.mjs
```

浏览器测试需要开发环境安装 `playwright` 并通过 `npx playwright install chromium` 安装浏览器；也可设置 `PLAYWRIGHT_CHANNEL=msedge` 使用已安装的 Edge。此依赖仅用于开发测试，不需要安装到 AstrBot 服务器。

测试使用模拟 HTTP 响应、“折枝”及同名不同 ID 示例，不连接 Immich 或 XWUID 服务。Pillow 依赖约束为 `>=10,<=13.0.0`，包含 13.0.0，不包含 13.0.1 或更高版本。

v1.1.0 使用 AstrBot 4.29.4、Pillow 13.0.0 在本地隔离目录验证，43 项 Python 测试与 12 项真实浏览器交互测试通过；未执行生产写入或真实机器人联调。检查覆盖同名角色保存、白芷自定义相册、规格筛选、角色交换、双类型选择、同步结果释放及 320–1440 像素布局。

v1.1.1 在相同 AstrBot/Pillow 版本下通过 55 项 Python 离线测试。新增验证覆盖真实图片预处理后的一图/多图、本地文件优先及网络回退，以及 WebUI 和聊天同步的面板图/背景图写入请求头；验证期间阻断外部网络连接，全部上传使用模拟接口，未对生产相册或图库执行写入。

v1.1.2 在 AstrBot 4.29.4、Pillow 13.0.0 下通过全部 76 项 Python 离线测试。新增验证覆盖共享相册同图跳过、分页及校验和格式、已有资产复用、上传时重复返回、相册重复关联、回收站、接口异常、失败继续及命令间缓存隔离。验证期间阻断外部网络连接，全部上传、创建相册和相册关联使用模拟接口，未执行生产写入或部署。


v1.2.0 在 AstrBot 4.29.4、Pillow 13.0.0 下通过全部 99 项 Python 离线测试及 16 项真实浏览器交互测试。验证覆盖引用合并转发、嵌套与图片数量截断、原有精确查重、单任务并发拒绝、聊天消费取消、状态读取竞争、实际 AstrBot SQLite/KV 覆盖与重新加载，以及页面重连和取消吸顶。Python 验证阻断外部网络，所有相册/图库写入均使用模拟接口；没有操作生产相册或图库，没有部署服务器。
